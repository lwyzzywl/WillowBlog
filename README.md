# 柳树小屋 · Willow Blog

一个温暖治愈风格的「个人博客 + 成长记录」单页应用。

技术栈：React 19 + Vite + Tailwind CSS v4 + Lucide React + canvas-confetti

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
npm run preview
```

## 模块

- 首页仪表盘：动态问候、每日一句、学习热力图、连续打卡、纸屑动画打卡按钮
- 计算机学习数：环形进度条 + 可打勾学习清单（划线动画）
- 项目实战日志：时间轴卡片、踩坑与灵感、复盘总结、GitHub链接直达
- 闪光点碎片：便利贴留言板 + 弹窗记录新闪光点
